# Morpion

Jeu de morpion (Tic-Tac-Toe) développé en HTML, CSS et JavaScript vanilla, jouable à deux en local.

## Fonctionnalités

- Grille 3×3 générée dynamiquement
- Alternance des tours entre joueur X et joueur O
- Détection automatique de la victoire
- Bouton de redémarrage

## Technologies

- HTML
- CSS
- JavaScript

## Lancer le projet

Ouvrir `index.html` dans un navigateur.
