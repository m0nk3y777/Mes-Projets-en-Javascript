# Snake

Jeu Snake classique développé en HTML Canvas et JavaScript vanilla.

## Fonctionnalités

- Déplacement du serpent avec les touches directionnelles
- Nourriture à ramasser pour grandir et marquer des points
- Système de score et de monnaie (1 pièce toutes les 4 pommes)
- Game Over en cas de sortie des limites

## Technologies

- HTML
- CSS
- JavaScript (Canvas 2D)

## Lancer le projet

Ouvrir `snake.html` dans un navigateur.
